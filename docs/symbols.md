# 認識する記号

認識器の出力語彙は、math-engineの`TeXInput`が解釈するLaTeXのトークンに限る。
関数名（`\sin`など）は1トークン、数字・文字は1文字1トークン、2次元の配置は`^`・`_`・`\frac{..}{..}`・
`\sqrt{..}`などの構造トークンで表す。

## 収集する単独記号（84種）

[お手本集](../data/prompts/v1.json)の`kind: "symbol"`。1人あたり各3回書く。

| 分類 | 記号 |
|---|---|
| 数字 | `0`〜`9` |
| 英小文字 | `a`〜`z`（関数名`sin`・`log`・`lim`などの文字も兼ねる） |
| 英大文字 | `A` `B` `C` `D` `E` `F` `X` `Y` |
| ギリシャ文字 | `\alpha` `\beta` `\gamma` `\delta` `\theta` `\lambda` `\mu` `\pi` `\sigma` `\phi` `\omega` |
| 演算子 | `+` `-` `\times` `\cdot` `\div` `/` `!` `,` `.` |
| 関係 | `=` `\neq` `<` `>` `\leq` `\geq` `\to` |
| 括弧 | `(` `)` `[` `]` `\{` `\}` `|` |
| その他 | `^{\circ}`（度） `\infty` `\sqrt{}`（根号） `\int` `\sum` `\prod` |

分数の横線は`-`と同じ形の長い横線であり、単独記号としては集めない（式のお手本から学ぶ）。

## 式のお手本（104式）

`kind: "expression"`。四則・分数・べき・根・関数・対数・階乗・絶対値・代数・方程式/不等式・
積分・微分・極限・総和/総積・行列・複合式を含む。各お手本はmath-engineで解釈できることを
`tools/check_prompts.py`で確認する。合成データの配置規則の検証と、実データでの評価・仕上げの学習に使う。
